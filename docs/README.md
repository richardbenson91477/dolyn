**dolen**

LLM inference in C

Based originally on "Qwen3.c" [https://github.com/adriancable/qwen3.c] and "Qwen3.5.c" [https://github.com/kroggen/qwen3.5-c], ultimately based on Andrej Karpathy's "llama2.c" [https://github.com/karpathy/llama2.c] 

Models supported: Qwen 3, Qwen 3.5, Qwen 3.6, Gemma 4, IBM Granite 4.1.

Currently supports dense (non-MoE) variants, text mode only.
